# CD3 Weather Station
To download the data, press the green "code" button and download a zip. :100::100::bangbang::fire::fire:  
A more convenient download method may be added later. :eyes::eyes:

EACH LINE IS FORMATTED AS:  
Date, Time, Wetness, Luminosity, Wind Direction, Corrected Wind Direction, Wind Speed,  Solar Radiation, Barometric Pressure, Sea Level Pressure, Station Level Pressure, Relative Humidity, Air Temperature, Dew Point, Absolute Humidity, Air Density, Wind Chill, Heat Index, Precipitation  

All values are a 5 minute average EXCEPT precipitation which is the total amount of precipitation in the last 5 minutes, after reporting the value it resets to 0 for the next cycle.
